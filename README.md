# Coursera Data Science Assignments Repository
This repository contains my solutions and deliverables for various courses and assignments completed on Coursera. Each folder or notebook corresponds to a specific lab exercise or graded assignment.

## Repository Structure

- labs/Contains Jupyter notebooks and supporting files for lab exercises (yfinance, web scraping, pandas, numpy, etc.).

- assignments/Contains final project submissions and peer-graded assignment notebooks.

- README.mdThis file, providing an overview and usage instructions.

## Notebooks and Exercises

### Lab Exercises

1. Stock Data Extraction (labs/stock_data.ipynb):

Using yfinance to extract historical stock prices.

Webscraping revenue data from Macrotrends.

2. Data Manipulation with Pandas (labs/pandas_tutorial.ipynb):

3. Numpy Arrays (labs/numpy_basics.ipynb):

### Graded Assignments

- Peer-graded Assignments (assignments/peer_reviews/):Screenshots and code for peer review tasks.

## How to Use

1. Clone the repository:

git clone https://github.com/MoonDSAI/coursera.git
cd coursera

2. Install dependencies:

pip install -r requirements.txt

3. Open Jupyter Notebook or Lab:

jupyter lab

4. Navigate to the desired notebook under labs/ or assignments/ and run cells sequentially.

## Screenshot Guidelines

- Save output from first cell of each question through the final result.

- Store images in screenshots/ with a clear naming convention (e.g., Q1_tesla_head.png).
